## 🔧 Local Development

1. Clone this repository:
   ```
   git clone https://github.com/[your-github-username]/react-8gza7n.git
   cd react-8gza7n
   ```

2. Install dependencies:
   ```
   npm install
   ```

3. Run the development server:
   ```
   npm start
   ```

4. Build for production:
   ```
   npm run build
   ```

## 📤 Deployment

This project is set up for automatic deployment to GitHub Pages using GitHub Actions. When you push changes to the main branch, the site will automatically rebuild and deploy.

### Manual Deployment:

1. Update your code and commit changes
2. Push to GitHub:
   ```
   git push origin main
   ```
3. The GitHub Actions workflow will automatically deploy your changes
